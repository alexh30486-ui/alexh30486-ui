# Publish your GitHub profile

1. Open your existing profile repository: https://github.com/alexh30486-ui/alexh30486-ui
2. Keep a backup of its current README before replacing it.
3. Put this package’s README.md at the repository root.
4. Upload the entire assets folder alongside README.md. Keep the filenames unchanged.
5. Preview the README on GitHub and commit the reviewed changes. This package has not been pushed for you.

Only README.md and assets/ are needed for the profile. SETUP.md and CONTENT-NOTES.md are delivery notes, not profile sections.

The wave and terminal graphics are local SVGs. Badges, typing text, and stats use third-party services; failures there do not remove the written introduction or project links. The terminal is a static profile illustration, not execution evidence.

Consider pinning ai301-coursework and your strongest independently documented projects. A fork alone does not communicate your contribution as clearly as the direct merged-PR link.
